# 규칙 탐정단

초등 4학년 1학기 6단원 규칙 찾기 연습용 정적 웹 게임입니다.
마을 지도를 이동하며 장소별 수학 단서를 해결하고, 모은 암호 조각으로 마지막 금고를 여는 구조입니다.

## 게임 구조

- 6개 장소: 시계탑, 시장 골목, 도서관, 정거장, 연구소, 금고실
- 장소별 4문제, 총 24문제
- 장소를 완료하면 암호 조각 1개 획득
- 모든 암호 조각을 지도 순서대로 입력하면 최종 사건 해결
- 정답 효과, 오답 흔들림, 힌트, 별 보상, 처음부터 다시하기 포함

## 디자인 방향

- Canva 인포그래픽 시안을 기준으로 지도형 학습 보드 톤 적용
- 편집 가능한 Canva 콘셉트: https://www.canva.com/d/bthI9Le5jJsifOo
- 화면 구성: 사건 요약 리본, 이동 지도, 문제 유형 범례, 암호 조각 보드, 최종 금고
- 색상 기준: 네이비, 청록, 골드, 코랄, 밝은 종이색

## 구성

- `index.html`: 화면 구조
- `styles.css`: 디자인과 반응형 스타일
- `game.js`: 장소, 문제 데이터, 지도 이동, 암호 진행 로직
- `assets/detective-office.webp`: 게임 배경 이미지

## 실행

`index.html`을 브라우저로 열면 바로 실행됩니다.

Vercel에는 별도 빌드 설정 없이 정적 사이트로 배포할 수 있습니다.
